# 普通模型端点接入状态

普通推理已切换为已部署 API 端点。Hitch 不再部署或管理普通推理引擎、GPU 账本、模型节点 RPC 或 Python 推理服务。

当前接口、冻结绑定、工具协议、取消、计量与历史读取说明见[模型推理指南](guide/zh-CN/model-inference.md)。固定版本上游部署与实机验收清单见[部署示例](../examples/external-inference/README.md)。真实单副本、TP=2、Gateway 双副本与静态训练/推理分卡的硬件验收仍需在目标环境记录，旧自研推理池证据不能替代新路径验收。

模型 manifest、CAS、历史锁与训练精确采集继续保留。旧服务应使用旧版本工具完成停止与物理释放确认后，再移除旧部署环境。
